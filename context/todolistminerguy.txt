Phase 2D: Pickaxe and Yield Upgrades

Goal: make upgrades directly affect mining rewards.

Upgrade effects
Upgrade	Effect
Pickaxe Power	More damage per hit
Better Pickaxe Tier	Higher ore yield
Luck	Higher chance for bonus drops
Backpack Size	More inventory slots
Stack Compression	Larger max stacks
Rare Finder	Higher chance for rare ores
Functional checklist
 Add yieldBonus from pickaxe upgrades.
 Add damageBonus from power upgrades.
 Add bonusDropChance from luck.
 Add pickaxe tier levels.
 Add upgrade cost scaling.
 Add max levels.
 Show upgrade effect text in UI.

Example:

function getOreYield(baseAmount) {
  const pickaxeBonus = player.upgrades.pickaxeTier * 0.25;
  const luckBonus = player.upgrades.luck * 0.05;

  let amount = Math.floor(baseAmount * (1 + pickaxeBonus));

  if (Math.random() < luckBonus) {
    amount += 1;
  }

  return amount;
}
